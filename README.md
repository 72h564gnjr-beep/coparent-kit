## Publish free on GitHub Pages (recommended)

No paid services. Needs a free GitHub account (Rich’s).

1. Create a new **public** GitHub repo (e.g. `co-parent-kit` or `custody-coparent-landing`).
2. Upload everything **inside** this `seo-landing/` folder to the repo root  
   (`index.html` and `assets/` at the top level — not nested under another folder).
3. In the repo: **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: `main` (or `master`) → folder **/ (root)** → Save
4. Wait 1–2 minutes. Site URL will be like:  
   `https://YOUR_USERNAME.github.io/REPO_NAME/`
5. Optional: set that URL as the canonical later, and share it on Pinterest pins instead of (or in addition to) the raw Gumroad link for softer SEO traffic.
